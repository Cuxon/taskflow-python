# TaskFlow — система учета учебных задач

## Назначение
TaskFlow — консольное приложение для первоначального учета учебных задач. На этапе ПР1 программа демонстрирует базовый сценарий: определяет приоритет задачи, ее статус и рассчитывает срок выполнения.

## Целевая аудитория
Студенты, которым необходимо быстро оценивать учебные задачи и контролировать их выполнение.

## Предметная область
Предметная область проекта — планирование и контроль учебных задач. Для дальнейшего развития приложения можно хранить задачи, пользователей, сроки, статусы и приоритеты в базе данных.

## Основные сущности
- учебная задача;
- пользователь;
- срок выполнения;
- приоритет;
- статус задачи.

## Основные функции
- определение приоритета задачи по срочности и важности;
- определение статуса задачи;
- расчет срока выполнения в днях;
- вывод краткого результата по задаче.

## План развития
На следующих этапах планируется:
- расширение программы с использованием коллекций, циклов и функций;
- добавление обработки файлов и исключений;
- реализация сущностей проекта в виде классов;
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация регистрации, аутентификации и авторизации пользователей;
- разработка REST API;
- контейнеризация приложения;
- настройка CI/CD.
