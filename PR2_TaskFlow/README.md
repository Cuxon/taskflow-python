# TaskFlow — система учета учебных задач

Консольное приложение для планирования и контроля учебных задач. Проект является
продолжением индивидуального проекта ПР1.

## Возможности
- просмотр списка учебных задач;
- добавление задачи;
- поиск задачи по названию;
- фильтрация по статусу;
- сортировка по приоритету;
- расчет приоритета;
- расчет срока выполнения;
- изменение статуса;
- сохранение и загрузка данных из JSON;
- обработка ошибок пользовательского ввода и файлов.

## Структура проекта
- `main.py` — точка запуска;
- `tasks.py` — функции работы с задачами;
- `storage.py` — чтение и запись JSON;
- `utils.py` — вспомогательные функции;
- `data/tasks.json` — данные приложения;
- `tests/` — автоматизированные тесты;
- `requirements.txt` — зависимости.

## Требования
- Python 3.x
- pytest
- flake8

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python main.py
```

## Тесты
```bash
pytest
```

## Проверка качества
```bash
flake8
```
