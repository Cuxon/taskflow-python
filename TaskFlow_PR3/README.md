# TaskFlow — ПР3

Система учета учебных задач. Проект ПР2 переработан под объектно-ориентированную модель.

## Что изменено в ПР3

- сущность учебной задачи представлена классом `Task`;
- пользователь представлен классом `User`;
- добавлены `__init__` и `__str__`;
- поведение задачи вынесено в методы `change_status()` и `is_overdue()`;
- коллекции содержат объекты `Task` и `User`, а не словари;
- JSON используется как внешнее хранилище;
- загрузка JSON создает объекты через `from_dict()`;
- сохранение объектов выполняется через `to_dict()`;
- функции ПР2 адаптированы к объектной модели;
- обновлены pytest-тесты;
- добавлены примеры по наследованию, полиморфизму, staticmethod, classmethod и декораторам.

## Объектная модель

`Task` хранит состояние учебной задачи: идентификатор, название, описание, приоритет, статус, срок и пользователя. Методы `change_status()` и `is_overdue()` реализуют поведение объекта.

`User` хранит идентификатор, имя и email.

Функции в `tasks.py` и `users.py` работают с коллекциями объектов. `storage.py` отвечает только за преобразование объектов в JSON и обратно, поэтому логика внешнего хранения не смешивается с поведением объектов.
